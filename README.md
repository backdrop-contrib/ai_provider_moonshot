# AI Provider Moonshot

Connect Backdrop’s AI features to Moonshot AI’s Kimi models. Use them for writing, code, and work with long documents. Use it for chat or text generation. Reasoning, image analysis, and tool calling depend on the selected model.

## Requirements

Backdrop CMS 1.x, PHP 8.2 or later, and the AI module, plus the Key module.

## Installation

1. Install and enable this module using the official [Backdrop CMS instructions](https://backdropcms.org/user-guide/modules).
2. Open **AI settings** at `admin/config/ai/settings` and enable the provider. Select the service credential you saved with the Key module.
3. Choose **Endpoint Region / Base URL** to match your account. Choose **Custom** and set **Custom Base URL** when using a compatible gateway.

Read the [module wiki](https://github.com/backdrop-contrib/ai_provider_moonshot/wiki) for setup details, supported operations, and troubleshooting.
